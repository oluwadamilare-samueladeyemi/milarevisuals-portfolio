Milare Visuals

A professional photography and media portfolio built with React and Vite.

Features

- Responsive Design
- Dark / Light Mode
- GitHub API Integration
- Project Search
- Contact Form Validation
- Dynamic Routing
- Project Details
- Timeline
- Skills Section

Technologies

- React
- Vite
- React Router DOM
- Context API
- GitHub REST API
- CSS

Installation

npm install

npm run dev

Build

npm run build
